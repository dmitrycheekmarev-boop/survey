# Конструктор опросников

Веб-приложение для психологического тестирования:
**FastAPI + SQLAlchemy 2.x / PostgreSQL + Jinja2 + Tailwind CSS**.

## Возможности

- Конструирование тестов: версии, вопросы (одиночный/множественный выбор,
  шкала Ликерта, открытый ответ), варианты ответа и ключи (баллы по шкалам).
- Шкалы: `sum`, `average`, `count`, `composite` (формулы через зависимости).
- Последовательности тестов и назначение их студентам.
- Прохождение тестов, автоматический расчёт и интерпретация результатов.
- Ручная оценка открытых ответов, статистика и журнал аудита.
- Ролевая модель: `admin`, `methodist`, `student`.

## Быстрый старт

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt

uvicorn main:app --reload
```

Приложение: http://127.0.0.1:8000
Документация API: http://127.0.0.1:8000/docs

## Настройка БД

Параметры подключения берутся из `.env` (`DB_USER`, `DB_PASSWORD`, `DB_HOST`,
`DB_PORT`, `DB_NAME`) либо из единого `DATABASE_URL`. Схема создаётся
автоматически при старте. Если PostgreSQL недоступен, включается резервный
SQLite (флаг `DB_ALLOW_SQLITE_FALLBACK=1`) — удобно для локальной разработки.

```

models.py      — ORM-модели (23 таблицы)
database.py    — подключение к БД, сессии, инициализация схемы
bot.py         — Telegram-бот (опционально)
templates/     — Jinja2-шаблоны (base.html + страницы)
```
