# Каталог тестов

Три методики в формате для загрузки в схему `schema.sql`. Состав таблиц тот же, что в спецификации. `attempts` стоит раньше `user_test_progress`: в документе порядок обратный, и скрипт падает на внешнем ключе.

Команды ниже запускать из папки `seed/`.

## Файлы

| Файл | Что это |
|---|---|
| `schema.sql` | схема, 23 таблицы |
| `catalog.json` | тесты, шкалы, вопросы, баллы |
| `catalog.schema.json` | проверка `catalog.json` |
| `response_pack.schema.json` | проверка пачки ответов |
| `example_packs.json` | пример, 6 пачек |
| `load.py` | загрузка в PostgreSQL и расчёт шкал |
| `build_catalog.py` | сборка `catalog.json` из docx |
| `requirements.txt` | `jsonschema`, `psycopg` |

## Тесты

| Код | Методика | Вопросов | Шкалы |
|---|---|---|---|
| `SJO` | СЖО, Леонтьев | 20 | 6, сумма |
| `REAN_BADMAEV` | Мотивация учебной деятельности, Реан, Бадмаев | 34 | 7, среднее |
| `POAK` | ПОАК | 12 | 4, сумма |

Коды вопросов: `SJO_q01` … `SJO_q20`, `REAN_q01` … `REAN_q34`, `POAK_q01` … `POAK_q12`. В бланках таких кодов нет, номер в коде совпадает с номером пункта. Версия у каждого теста `1`, опубликована. Тип всех вопросов `scale`.

## Значения ответов

Сначала ищется `raw_value`, потом текст варианта без учёта регистра.

СЖО, слева направо по бланку 3-2-1-0-1-2-3:

| `raw_value` | текст |
|---|---|
| `LEFT_3` | Левое, 3 |
| `LEFT_2` | Левое, 2 |
| `LEFT_1` | Левое, 1 |
| `BOTH` | Оба равны (0) |
| `RIGHT_1` | Правое, 1 |
| `RIGHT_2` | Правое, 2 |
| `RIGHT_3` | Правое, 3 |

В тексте вопроса оба полюса: `ЛЕВОЕ: … || ПРАВОЕ: …`.

Реан–Бадмаев: `1` … `5`.

ПОАК: балл `0` … `4` или слова «никогда», «редко», «иногда», «часто», «всегда». «Никогда» это `0`. Если в выгрузке «никогда» придёт как `1`, оно совпадёт с «редко».

## Пачка ответов

Файл импорта — массив объектов.

```json
{
  "respondent": "r0001",
  "test_code": "POAK",
  "version": 1,
  "submitted_at": "2026-09-01T10:00:00Z",
  "source": "form",
  "answers": [
    {"question_code": "POAK_q01", "value": "2"}
  ]
}
```

`respondent` становится `users.login`. `version` можно не указывать, тогда берётся последняя опубликованная. `submitted_at` можно не указывать, тогда ставится время импорта. `source` в базу не пишется.

Пачка принимается целиком или отклоняется целиком. Респондента загрузчик создаёт сам: роль `student`, пароль `!`, войти под ним нельзя. Повтор с тем же `submitted_at` пропускается. Без `submitted_at` повтор создаст вторую попытку.

## Загрузка

```bash
createdb tests
psql -v ON_ERROR_STOP=1 tests -f schema.sql
pip install -r requirements.txt
python3 load.py catalog catalog.json
python3 load.py packs example_packs.json
python3 load.py scores
```

Подключение: `DATABASE_URL`, по умолчанию `dbname=tests`.

Если версия теста уже есть, загрузчик её не перезаписывает. Изменение ключа — это `version_no` 2.

Сборка каталога заново: `python3 build_catalog.py [папка_с_docx]`. Без аргумента docx ищутся на уровень выше `seed/`. Исходные docx в репозиторий не входят, готовый `catalog.json` лежит рядом.
